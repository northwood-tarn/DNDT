# Locked base armor artwork

These six base armor images were approved and locked on 2026-07-22:

- `leather_armor.png`
- `hide_armor.png`
- `studded_leather.png`
- `chain_mail.png`
- `half_plate.png`
- `plate_armor.png`

Each runtime asset is exactly 160×224 pixels. Its corresponding `_master.png`
is the locked high-resolution painted source. Preserve both files exactly: do
not crop, regenerate, reinterpret, replace, recolor, or paint over them unless
the user explicitly unlocks the specific armor image.

Magical armor variants must preserve the applicable locked base image and add
their treatment separately. They are not part of this locked base set yet.
