# Shield icon treatment

Shield variants reuse the exact approved base shield image for their shield type: Buckler, Shield, or Tower Shield.

Modified and magical shields are distinguished through a treatment that follows the shield's outer edge. The treatment may expand into a clearly readable elemental perimeter when required by the item. Preserve the base shield's silhouette, proportions, upright centred orientation, and face. Do not use the weapon system's top-left badges for shields.

For the Aegis of Light, the base is `shield.png` and the modification is a broad but gauzy perimeter of warm gold-and-ivory holy light around the shield's outer edge. It must not read as flame.

Only redesign the shield face, add heraldry, or depart from edge treatment when explicitly requested.
