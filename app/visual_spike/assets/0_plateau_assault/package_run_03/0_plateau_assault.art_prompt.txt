STYLE

Dark fantasy underground combat plate. Open-air cavern field, not a tunnel. Painterly negative-ink direction, dark negative space, readable surfaces, restrained detail, no decorative grit. Combat is globally readable because the Lanterna flares in danger, but the mood remains dark and severe.

The final image must not look like the control grid with texture applied. The tactical grid is a hidden construction scaffold, not the visible landscape language. Adjacent same-terrain cells should merge into continuous terrain masses with natural painterly variation. Cell borders, diamond seams, repeated tile texture, and per-cell stone slabs are rejected unless a specific authored terrain element requires that boundary.

Altitude is a primary visual contract, not a color tint. The +4 plateau must read as physically elevated above the low ground through cliff faces, occlusion, cast shadow, visible vertical rock, and coherent edge treatment. Slopes must read as continuous inclined terrain bands, not flat green-textured diamonds.

Paint in broad masses before detail. Favor clear silhouettes, empty dark chasm, and a few controlled marks over noisy surface rendering. The map should feel like a dark fantasy battlefield, not a board tile set.
