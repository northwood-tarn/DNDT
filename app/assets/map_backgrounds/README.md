# Map backgrounds

Canonical home for authored exploration-map background images.

- Images are 1920 × 1080 pixels at native resolution.
- Filenames use the stable area ID: `aNN_area_name.ext`.
- Example: `a03_ritual_road.png`.
- Area bundles refer to backgrounds using app-relative paths such as `./assets/map_backgrounds/a03_ritual_road.png`.

Background images live here; navigation, occlusion, water, and other area metadata live in the matching folder under `app/areas/`.
